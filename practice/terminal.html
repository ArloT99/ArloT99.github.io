How to use vim

How to Open/Close vim

To open vim type vim filename.filetype into the terminal.

To close vim, hit escape to exit insert mode, then press :q to close without saving or use :wq to save and close.

How to Navigate vim

To navigate vim use either hjkl or the arrow keys.

How to Type in vim

To type, hit i to enter insert mode, then enter text.

vim shortcuts

  • o: Start a new line below
  • w: Jump to start of next word
  • b: Jump to start of previous word
    1. O: Create a new line above the current line
    2. a: Insert after the cursor
    3. A: Insert at the end of the line
